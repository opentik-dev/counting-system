# Roadmap

## Completed

- Deterministic line-crossing counter for cartons and pallets.
- SQLite event persistence and auditable evidence references.
- Explicit pallet-capacity rules with incomplete summaries when capacity is unknown.
- Offline annotation workbench and dataset validators.
- Reproducible CPU baseline training wrapper.

## Next gate

- Capture a fixed-view video from the target warehouse.
- Define the manual ground-truth protocol and acceptance error threshold.
- Keep the acceptance set separate from supplemental training data.

## Later

- Segmentation/tracking adapter for the validated scene.
- RTSP/ONVIF camera input.
- Review API and dashboard.
- ERP integration and multi-camera correlation.

The project will not claim production counting accuracy before the next gate is
completed.
